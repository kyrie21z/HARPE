# SPEC.md —— 规格约束与设计边界

> **定位**：回答《HARPE》是什么、不是什么，定义不可违背的硬性技术规格与数值上下限。

---

## 1. One-Liner（一句话定义）

《HARPE》（弑神利刃）是一款以古希腊神话英雄珀尔修斯为主角、采用纯键盘方向操控、强调“瞬步拉扯、神盾弹反、蓄力突斩”与奥林匹斯神明祝福组合的 **2D 俯视角动作肉鸽（Top-Down Action Roguelite）**。

---

## 技术基线与输入契约

- 引擎统一使用 **Godot Engine v4.7.2-stable 官方 Standard 版**，多设备版本必须一致，不使用 Mono/.NET C# 版。
- 脚本语言为 **GDScript 2.0**。
- 核心输入如下；实际绑定在 `project.godot` 的 `[input]` 中核验。下表定义核心绑定，额外绑定以配置为准，发现契约冲突时报告差异。

| 动作 | 核心绑定 | 行为 |
| --- | --- | --- |
| `move_up` / `move_down` / `move_left` / `move_right` | W / S / A / D | 移动及朝向 |
| `dash` | Shift | 消耗充能的瞬步 |
| `attack` | 鼠标左键 | 点按轻击，长按蓄力重斩 |
| `parry` | 鼠标右键 | 盾牌招架 |

## 2. 核心循环（Core Loop）

```text
南面石门迈入密室（大门轰然闭合封锁战场）
       ⬇
30秒微观博弈（走位 ➔ 盾牌弹反/瞬步拉扯 ➔ 镰刃轻重斩击破）
       ⬇
清空单室恶灵（兑现前室选门承诺之专属战利品：雅典娜/赫尔墨斯/锻炉神力三选一，或仙馔密酒回血）
       ⬇
北壁并列开启 1~3 扇出口石门（一字横向排开，门楣标明下室专属战利品与光芒符文）
       ⬇
玩家纵览北壁选项，迈步跨入心仪神门
       ⬇
自下一密室南门步入（北出南入，空间纵深推进）
       ⬇
3 密室梯度循环 ➔ 穿过终极凯旋之门达成试炼大捷 / 死亡无缝即时重开
```

## 3. 关键数值边界（Balance Boundaries）

在调优或新增功能时，数值必须保持在以下安全区间内：

| 参数项 | 基准值 | 安全可调区间 | 约束说明 |
| :--- | :--- | :--- | :--- |
| **玩家最大生命值 (Max HP)** | 100.0 | [80.0, 200.0] | 不宜过高，保持紧张感 |
| **玩家基础移速** | 240.0 px/s | [200.0, 320.0] | 保证能轻微跑赢近战怪，但无法完全脱离投射物 |
| **瞬步（Dash）次数上限** | 2 次 | [1, 3] | 禁止无限连续冲刺 |
| **瞬步距离 / 速度** | 200 px / 700 px/s | [150, 260] px | 瞬步必须干脆，带有无敌残影 |
| **瞬步充能恢复时间** | 1.2 秒/次 | [0.8, 1.8] s | 弹反成功可直接重置充能 |
| **神盾招架判定窗口** | **0.12 秒** | **[0.10, 0.15] s** | **核心高风险窗口，严禁超过 0.18s（避免沦为无脑按键）** |
| **三段轻击连招位移 (Lunge)** | 1段: 25px / 2段: 30px / 3段: 55px | [20, 65] px | 刀刀向前压进，第三段重劈大幅破空突进 |
| **三段轻击连招伤害** | 1段: 20 / 2段: 25 / 3段: 45 | [15, 60] | 递增爆发，打满一套 90 伤斩杀基础怪 |
| **三段连招输入缓冲窗口** | 0.45 秒 | [0.35, 0.60] s | 允许连续点按平滑派生下一击 |
| **冲刺攻击位移 / 初速度** | 620.0 px/s (追加滑行约 75px) | [500.0, 750.0] px/s | 继承瞬步动量突刺，压低重心穿梭 |
| **冲刺攻击伤害** | 30.0 | [25.0, 45.0] | 强于轻击1段，打先手突进，命中后无缝派生2段回砍 |
| **重斩最大蓄力时间** | 0.5 秒 | [0.35, 0.70] s | 蓄力太长会导致战斗停滞 |
| **受击顿帧时间 (Hit-stop)** | 0.05 ~ 0.14 秒 | [0.04, 0.15] s | 1/2段微顿，3段重劈与破灭重斩强顿帧 |
| **镜头震屏强度 (Shake)** | 2.5 ~ 8.0 px | [2.0, 18.0] px | 招架/重击强震，平砍1/2段微颤，3段重击适度震屏 |
| **轻击 1/2 段受击硬直 (Stun)** | 0.22s / 0.26s | [0.20, 0.30] s | 打断普通怪起手，支持连招压制 |
| **冲刺攻击受击硬直** | 0.32s | [0.28, 0.40] s | 突进先手制敌，压制小怪动作 |
| **轻击 3 段终结重劈硬直** | 0.45s | [0.38, 0.55] s | 强力推开并造成大僵直，破精英怪霸体 |
| **破灭重斩受击硬直** | 0.60s | [0.50, 0.80] s | 强力打断破霸体，将怪物击飞深陷大硬直 |
| **精英怪破霸门槛** | 0.40s | [0.35, 0.45] s | 轻击不硬直，仅第3段重劈与破灭重斩破除霸体 |

## 4. 明确不做的事（Non-Goals）

为了保证项目工程不失控，以下设计**明确禁止加入**：

1. **不做双摇杆常态陀螺自转（Twin-stick）**：
   - 坚决杜绝跑动时鼠标晃动导致角色全身旋转的廉价感；严格遵循 Hades 交互（常态跑动锁定 WASD，出招瞬间强制瞬切对准鼠标光标）。
2. **不做复杂的局外数值养成（Meta-progression）**：
   - 在当前开发阶段，禁止加入外部天赋树、永久攻击力+1、装备强化等拖慢核心手感迭代的局外积累。
3. **不做庞大的程序化无尽地牢生成**：
   - 聚焦于经典肉鸽密室与四向石门空间严密衔接闭环，不引入超大迷宫或无底大地图算法。
4. **不做重型外部依赖**：
   - 严禁引入外部物理插件或非标准 .NET 扩展，保持上述技术基线的轻量运行。
