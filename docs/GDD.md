# 《HARPE》（极刃 / 哈尔珀）游戏设计文档 (GDD)

## 一、项目概述
- **游戏名称**：HARPE（全大写）
- **中文代号**：极刃 / 哈尔珀
- **游戏类型**：俯视角 2D 动作肉鸽（Top-Down Action Roguelite）
- **核心内核**：**登峰造极（Mastery）与高风险取舍（Risk & Reward）**
- **目标平台**：PC (Steam / itch.io)
- **开发引擎**：**Godot Engine v4.7.2-stable (Standard 官方版)** + GDScript 2.0（全设备统一锁定）

## 二、官方简介与核心亮点定稿（Steam / 宣发版）

> **《HARPE》**
> 
> 手执弑神利刃，向死而生。这是一款以刀尖博弈与高风险取舍为核心的俯视角动作肉鸽。
> 
> - **斩落美杜莎的首级**：深入绝境，直面令万物石化的蛇发女妖，在死线边缘完成弑神壮举。
> - **毫厘之间的锋芒对决**：以极速瞬步穿梭破阵，在刀锋临面的刹那精准弹反，或以命相搏蓄势挥出毁灭重斩，一瞬定生死。
> - **登峰造极的三大极境**：残影瞬步、绝命弹反、破灭重斩自由构筑，让每一次绝境挥刃都化为撕裂黑暗的暴烈回响！

## 三、世界观与终极目标（Narrative & Goal）
- **神话背景**：
  取自希腊神话英雄史诗。凡直视美杜莎之眼者皆化为死石，凡人看似陷入必死绝局。
  挑战者手执神使赫尔墨斯赐予的弑神神兵【HARPE】（带勾弯刃）、脚踏飞鞋、手持青铜反光之盾，深入黑暗巢穴。
- **终极通关目标**：
  突破深渊怪潮，斩落蛇发女妖美杜莎的首级！
- **Boss 战机制共鸣**：
  美杜莎释放致命的石化凝视/光线，玩家必须在命中的刹那使用【弹反】借势反射光芒使其陷入硬直破绽，随后接上满蓄力重斩一击封喉。

## 四、核心操作集（Input Mapping）

| 操作按键 | 核心动作 | 机制定位与收益 | 风险代价与取舍（博弈） |
| :--- | :--- | :--- | :--- |
| **WASD** | 基础移动 | 调整站位、拉扯空间、引导敌人面向 | 基础移速无法躲避大范围爆发攻击 |
| **Shift** | **极速瞬步 (Dash)** | 极速切入/脱离战场，带短暂无敌帧 | **充能限制（如 1~2 格）**：不可连续无脑滥用；用完进入充能真空期 |
| **鼠标左键 (点按)** | **轻击 (Light Attack)** | 前摇极短，快速压制弱小敌人、试探 | 伤害低，无法打断精英怪蓄力与霸体 |
| **鼠标左键 (长按)** | **破灭重斩 (Heavy Attack)** | 倾尽全力蓄势，挥出范围巨大、毁灭级重击 | **贪刀代价**：蓄力期间移速锐减或硬直，若被击中承受巨大伤害 |
| **鼠标右键** | **绝命弹反 (Parry)** | 毫秒级打铁判定，格挡近战并削减韧性，反弹远程子弹 | **时机严苛**：按早按晚直接硬吃伤害；成功可瞬间重置瞬步充能 |

## 五、三大肉鸽构筑流派（Build Synergy）

游戏中玩家通关房间获得三选一强化，围绕三大极致追求展开：

1. **残影瞬步流（速之极境）**：
   - 追求极致机动与连斩。
   - 强化词条：瞬步穿透斩击、瞬步留下嘲讽幻影、瞬步后下一次蓄力瞬间满段。
2. **绝命弹反流（准之极境）**：
   - 追求极致时机与绝对防御反杀。
   - 强化词条：弹反成功引发全屏雷暴、弹反远程分裂追踪、弹反完美时空（子弹时间）。
3. **破灭重斩流（力之极境）**：
   - 追求极致破坏力与大开大合。
   - 强化词条：多段过载蓄力、蓄力霸体减伤、吸血重斩、挥刀剑气波动。
4. **跨流派质变联动（Synergy）**：
   - 例：【刚体反击】—— 完美弹反不仅重置 Shift，下一次长按直接免去蓄力时间，瞬间轰出破灭重斩！

## 六、MVP 2 周开发范围（Scope Control）
遵循 EP.01 原则，严控项目边界，杜绝新手范围失控：
- **阶段一（核心手感与闭环）**：
  - 单一竞技场封闭房间；
  - 1 个玩家角色（WASD + Shift + 轻击/蓄力 + 弹反）；
  - 2 种敌人：①近战狂暴怪（引诱弹反） + ②远程弹幕怪（引诱反弹子弹）；
  - 打击感三要素：**顿帧（Hit-stop） + 屏幕微震（Screen Shake） + 清脆音效与金属火花**。
- **阶段二（基础肉鸽循环）**：
  - 波次刷新 + 通关三选一词条选择界面。
