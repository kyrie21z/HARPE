# 手柄全套控制、双摇杆瞄准与 UI 焦点适配支持

## 问题与动机

- 玩家需求：加入主流手柄（Controller / Gamepad）控制支持，实现俯视角动作肉鸽的核心大屏与手柄游玩体验。
- 关键挑战：
  1. 键鼠操作下出刀和蓄力深度依赖 `get_global_mouse_position()` 屏幕坐标，若直接在手柄上使用会导致角色朝屏幕静止的光标自转，无法正常瞄准敌人。
  2. 瞬步在中立状态（摇杆回中）时需像《Hades》一样朝当前面朝方向冲刺，而不是朝向鼠标位置。
  3. 神力三选一界面（BoonSelectUI）需要支持手柄焦点导航（D-Pad / 摇杆左右切卡、A键确认），以及面板快捷按键直接选卡（X / Y / B）。
  4. 手柄震动反馈（Haptics Rumble）缺失会严重影响近战与弹反的击打爽快感。

## 尝试与条件

1. **InputMap 全量手柄映射配置（`project.godot`）**：
   - **移动（`move_left/right/up/down`）**：左摇杆（Joypad Axis 0/1）+ 十字键（D-Pad Buttons 11/12/13/14），死区设为平滑的 0.3。
   - **攻击（`attack`）**：Xbox X 键（Button 2）/ RT 扳机键（Axis 5）。
   - **瞬步（`dash`）**：Xbox A 键（Button 0）/ RB 肩键（Button 10）。
   - **镜盾弹反（`parry`）**：Xbox B 键（Button 1）/ Y 键（Button 3）/ LB 肩键（Button 9）/ LT 扳机键（Axis 4）。
   - **瞄准（`aim_left/right/up/down`）**：右摇杆（Joypad Axis 2/3）。
2. **设备输入源无缝动态热切换与瞄准解耦（`Player.gd`）**：
   - 增加 `_input()` 监听，自动检测最近一次输入设备类型（`is_using_gamepad`）。
   - 重构瞄准系统为 `_snap_to_aim()`：
     - 手柄模式下：优先检测右摇杆倾斜向量；若未推右摇杆则自动跟随左摇杆移动朝向；摇杆全回中时坚守当前朝向，绝不吸附电脑鼠标光标。
     - 手柄中立瞬步：摇杆回中时朝面朝正前方瞬步（经典哈迪斯手感）。
3. **沉浸式手柄震动反馈（Controller Haptics Rumble）**：
   - 弹反大成功：强震动 `_rumble(0.8, 1.0, 0.22)`。
   - 破灭重斩释放：沉重震动 `_rumble(0.6, 0.9, 0.16)`。
   - 受伤受创：短促震动 `_rumble(0.5, 0.6, 0.14)`。
   - 瞬步掠空：微震动 `_rumble(0.18, 0.0, 0.08)`。
4. **祝福选择 UI（BoonSelectUI）手柄适配**：
   - 生成卡牌时调用 `cards_container.get_child(0).call_deferred("grab_focus")`，手柄左右摇杆/十字键可自由切卡。
   - 卡牌获得焦点时同步触发高亮发光与 `1.04` 倍微缩放动效。
   - 支持手柄面板按键直接快捷选卡（X = 第1张，Y = 第2张，B = 第3张）。
   - 更新所有祝福卡牌的按键徽章为键鼠+手柄双显示（如 `[ A / Shift ] 瞬步`、`[ X / 左键 ] 轻击`、`[ B / LB / 右键 ] 镜盾`）。

## 观察与证据

| 评估项 | 键鼠模式表现 | 手柄模式表现 | 判定依据 |
|---|---|---|---|
| 移动控制 | WASD 8向移动 | 左摇杆 360° 无极模拟量移动 + D-Pad | `InputMap` 映射与测试 1 |
| 挥刀/出招朝向 | 鼠标光标瞬瞄 | 左摇杆朝向或右摇杆独立瞄准（双摇杆机制） | `test_gamepad_controls.gd:53` |
| 中立静止瞬步 | 朝鼠标光标冲刺 | 朝面朝前方顺畅冲刺（无需推摇杆） | `test_gamepad_controls.gd:57` |
| 神力三选一界面 | 鼠标悬停并点击选择 | 自动高亮焦点，左/右摇杆选卡，A 键确认，或 X/Y/B 快捷选卡 | `test_gamepad_controls.gd:79` |
| 触觉打击反馈 | 屏幕震动 + 顿帧 | 屏幕震动 + 顿帧 + **手柄双马达高精震动** | `Input.start_joy_vibration` |

## 解释与经验

- 俯视角动作游戏支持手柄的关键不仅是 InputMap 键位绑定，更核心在于**朝向解算完全脱离屏幕绝对坐标**。必须建立设备感知的定向逻辑，在检测到手柄操作时切断鼠标全局坐标覆盖。
- UI 交互在手柄下的最佳实践是**焦点自捕获（Auto Grab Focus）与双输入通道（Focus+Confirm 与 Direct Shortcuts）**，让玩家既可以沉浸式按键浏览，也可以在熟练后一键快选。
