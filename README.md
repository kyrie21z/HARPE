# HARPE

> **手执弑神利刃，向死而生。**  
> 一款以刀尖博弈与高风险取舍为核心的俯视角动作肉鸽游戏（Top-Down Action Roguelite）。

---

## 🎮 游戏核心玩法与亮点

- **斩落美杜莎的首级**：深入绝境，直面令万物石化的蛇发女妖，在死线边缘完成弑神壮举。
- **毫厘之间的锋芒对决**：以极速瞬步穿梭破阵，在刀锋临面的刹那精准弹反，或以命相搏蓄势挥出毁灭重斩，一瞬定生死。
- **登峰造极的三大极境**：残影瞬步、绝命弹反、破灭重斩自由构筑，让每一次绝境挥刃都化为撕裂黑暗的暴烈回响！

详细游戏设计规范请参阅 [docs/GDD.md](docs/GDD.md)。

---

## 🛠️ 技术栈与多设备开发指南

### 1. 引擎与环境要求
- **引擎**：**Godot Engine v4.7.2-stable (Standard 官方版)**，请保持各设备版本严格一致（严禁使用 Mono / .NET C# 版）
- **语言**：GDScript 2.0

### 2. 跨设备开发说明
- 本仓库已配置严密的 `.gitignore`，各设备的本地缓存（`.godot/` 导入缓存）及本地绝对路径配置不会互相干扰；
- 新设备只需克隆本仓库并在 Godot 4 中点击“导入”并选择 `project.godot` 即可启动开发；
- AI 协作规范请参阅 [AGENTS.md](AGENTS.md)。
