# 上下文前置语（Context Prelude 模板）

> **使用场景**：在开启一个新对话、或者向 AI 指派一个跨度较大的中大型任务时，将本段作为前置提示词发送。它能防止 AI 读全仓库导致 Token 浪费或产生幻觉，强制 AI 遵守我们的底线。

---

## 📋 复制以下模板使用：

```markdown
你正在协助开发 Godot 4.7.2 俯视角 2D 动作肉鸽项目《HARPE》（弑神利刃）。
项目的规范与客观规则在：docs/bible/（_index.md, SPEC.md, MODULES.md, EXPERIENCE.md）。
历史实验与研发避坑记录在：docs/dev_logs/records/。

开始任务前，请严格遵守以下协作准则：
1. 先查阅 docs/bible/_index.md，理解【绝对不变量清单】与速查表。
2. 根据本次任务意图，精准只查阅 1~2 个最相关的模块文档，不无脑扫描全仓库：
   - 涉及数值/规则边界 ➔ 读 SPEC.md
   - 涉及系统新增/信号修改 ➔ 读 MODULES.md
   - 涉及手感/打击感调优 ➔ 读 EXPERIENCE.md
3. 若任务涉及 3 个以上模块或跨系统调用，先停下来与我确认方案和依赖范围，不要直接动手写代码。
4. 任何改动严禁违反【绝对不变量清单】（如：严禁加鼠标自瞄、严禁监听 tree_exited、碰撞状态修改强制 set_deferred）。如有冲突，主动拒绝并说明理由。
5. 所有暴露参数必须使用 @export，严格遵循 GDScript 2.0 静态类型注解与命名规范。

本次任务描述：
{在这里填写您要 AI 做的事情，例如：新增雅典娜反弹祝福并关联 UI}
```
